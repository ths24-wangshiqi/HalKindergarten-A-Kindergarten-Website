# HalKindergarten — A Kindergarten Website

幼稚園を紹介するWebサイトです。

## 概要

幼稚園の魅力や雰囲気をWebサイトを通じて分かりやすく伝えることを目的に制作しました。

HTMLでページの構造を作成し、CSSでレイアウトやデザインを整え、JavaScriptを使用して画面の動きを実装しています。

シンプルで見やすいデザインを意識し、訪問者が必要な情報を直感的に確認できるWebサイトを目指しました。

## 使用技術

- HTML
- CSS
- JavaScript

## プロジェクト構成

- `index.html`：Webサイトのメインページ
- `css/`：スタイルシート
- `img/`：画像ファイル
- `app.js`：JavaScriptによる動作処理

## 制作目的

HTML・CSS・JavaScriptを用いたWebサイト制作を通して、フロントエンド開発の基礎と、Webデザインやユーザーインターフェースの実装について学ぶことを目的としています。
